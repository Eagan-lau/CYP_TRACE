# Code and data licences

Project-owned code is distributed under the MIT licence in `LICENSE`.
`inference/LICENSE` retains the inference code's existing MIT notice.
Third-party data retain their source licences and attribution requirements.

The open UniProt–Rhea subset uses CC BY 4.0 sources, with attribution and
transformation details in `paper/ATTRIBUTION_OPEN_CORE.md`. Human label inputs
and derivatives are described in `ATTRIBUTION.md` and
`paper/ATTRIBUTION_HUMAN_DATA.md`.

Historical P450Rdb, BRENDA and SABIO-RK bulk files, CLEAN model assets and the
full mixed-source reaction index are excluded from this distribution.
Their acquisition and access conditions are documented in
`paper/RESTRICTED_DATA_AND_REVIEWER_ACCESS.md`. The MIT code licence does not
grant rights to redistribute those assets.
